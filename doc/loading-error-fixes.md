# 加载错误提示与插件版本策略

错误提示采用统一格式：“错误代码：… / 原因：…”。优先保留系统、网络、平台和媒体错误码；没有原始错误码时使用对应功能的错误码。没有具体原因时明确说明未返回原因，不猜测故障。

## 提示位置

| 场景 | 显示位置 |
| --- | --- |
| 搜索、歌单、排行榜、歌手与专辑、本地歌单、下载列表 | 页面原有错误区域和重新加载按钮 |
| 聚合搜索 | 失败平台旁显示代码、原因，保留单个平台重试 |
| 音频、歌词、评论、换源匹配 | 播放状态或对应面板 |
| 列表封面 | 占位区域错误标记，悬停查看完整代码和原因 |
| 插件商店、安装、导入、导出、清理 | 商店提示和插件卡片 |
| 音源导入、主题、更新、Cookie 歌单、WebDAV、备份、音频标签 | 对应设置页或已有操作提示 |
| 页面初始化、组件、后台工作线程及未处理异常 | 可关闭的页面错误提示；初始化失败提供重新加载 |
| 主窗口或桌面歌词主文档无法加载 | 原生对话框显示 Chromium 错误码及原因，可重新加载 |

主动取消、离开页面和切歌产生的正常取消不作为全局加载失败弹出。可恢复的中间重试沿用原有流程，最终失败显示原因。无 DOM 的后台环境只保留错误信息，通过工作线程及主进程通信传给界面。

诊断保留可用的底层代码；跨进程传递时使用可恢复的代码前缀，防止 Electron 或工作线程序列化丢弃自定义字段。显示前去掉堆栈、控制字符、URL 用户名密码及查询参数，并隐藏常见凭据字段。

## 插件版本

新版本文件和安装登记成功后删除旧目录，只加载新版本；运行时失败不回退。历史 `previous`、`pending` 及旧回退提示会迁移清理。用户偏好和停用状态保留，更新不能自行启用已停用的插件。

## 验证范围

2026-09-22：178 项相关基础测试及 63 项 Electron 界面检查通过；相关源码 ESLint、差异格式检查，以及主程序、主界面和桌面歌词的生产构建通过。未执行整仓所有测试。构建和临时验证文件位于 Git 忽略目录。

使用独立临时用户目录和生产构建进行故障注入，验证本地歌单及下载列表读取失败、HTTP 404 封面、聚合搜索 HTTP 403、插件主窗口和桌面歌词激活失败、备份磁盘写入失败，以及全局错误提示和正常取消。

基础测试覆盖错误码及原因提取、IPC 传递、敏感字段清理、窗口加载错误、旧插件清理、配置与备份事务、下载、Cookie 和 WebDAV。界面回归覆盖重试、插件更新及停用、导入导出、重启、列表加载、下载管理、标签编辑与播放队列。在线音乐服务的真实故障原因取决于上游返回信息。
