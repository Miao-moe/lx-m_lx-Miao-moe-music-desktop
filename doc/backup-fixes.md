# 手动备份与配置保存修复（D01–D08）

入口为「设置 → 备份与恢复」中的手动 `.lxmc` 导入、导出。导入后先预览内容，再勾选恢复类别；歌单还可以逐个选择。

## 修复明细

| 编号 | 调整 |
| --- | --- |
| D01 | 导出等待压缩、完整写入、刷新到磁盘及替换目标文件完成后才提示成功。写入失败显示错误，并保留已有备份。 |
| D02 | 读取、解压、解析、校验及恢复失败均返回界面；成功提示在整个恢复完成后显示。 |
| D03 | 输入文件上限 64 MiB，解压后上限 256 MiB；检查对象层级、字段类型、数量、重复标识、歌曲元数据、下载状态、歌词和插件配置，拒绝不安全的配置文件名。 |
| D04 | 歌单、下载记录和自定义歌词使用同一数据库事务；配置文件配合持久化恢复记录一起提交。任一步失败回滚，重启时先处理未完成恢复。若回滚本身失败，保留恢复记录并阻止后续配置写入。 |
| D05 | 新的所有数据备份加入下载记录、自定义歌词、插件偏好、已安装插件的启用状态及音效预设。 |
| D06 | 预览显示文件名、备份时间、分类数量、歌单及覆盖规则，支持按类别和歌单选择；取消不会修改数据。 |
| D07 | 主进程配置保存改为异步队列，合并同一批变化，退出前等待待写入项完成。 |
| D08 | 配置及相关缓存仅在文件成功提交后更新；失败保留上次已保存状态，并向等待保存结果的调用方返回错误。并发设置变化按已提交数据合并。 |

## 恢复范围

- 歌单：相同 ID 替换内容，新 ID 追加，未选择的歌单保留。
- 设置：覆盖备份中提供的字段，其余字段保留；包含账号及网络设置。
- 下载记录：相同任务 ID 替换，新任务追加；未完成任务恢复为暂停，原有文件路径保留，不自动启动下载。恢复这类数据前需要暂停正在进行的下载。
- 自定义歌词：替换相同歌曲 ID 的编辑歌词，保留其他歌曲的歌词。
- 插件：恢复同名偏好文件、音效预设和已安装插件的启用状态；插件偏好在重启应用后生效。

音频文件、插件程序、自定义源脚本、主题图片和快捷键不包含在此备份内。备份是压缩文件，未加密。新所有数据文件使用 `allData_v3`；旧版手动备份仍可导入，单独导出的列表和设置继续使用 v2 格式。
