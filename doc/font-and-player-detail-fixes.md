# 自定义字体与播放详情页

- 设置 → 基本设置 → 字体：分别选择主要字体、次要兜底字体，显示实时预览，支持恢复默认。
- 可选择系统已安装字体，也可导入 TTF、OTF、WOFF、WOFF2 文件；单个文件限制 32 MB。
- 导入先由 Chromium 验证，再以内容哈希保存到数据目录 `fonts/`。重复导入复用同一份文件；原文件移动或删除不影响重启后的使用。
- 字体选择沿用 `common.font`，兼容旧设置。解析保留带逗号、引号的字体名；未指定主要字体时保留系统默认的第一顺位，不把兜底字体误设为主要字体。
- 字体导入、读取和保存失败显示错误代码和原因；缺失字体时仍能使用其余兜底字体。
- Folia 1.2.3 分别接收两个字体名称，避免把整段列表识别成一个名称。新建预览和播放页的 iframe 同步加载所选导入字体；配置不变时复用字体数组，保持原有消息去重。

## 窗口拖动

主程序为插件播放详情页保留顶部中间的原生拖动区域，避开左右两侧窗口按钮。该区域放在插件节点之后，避免 Electron 按文档顺序处理时被插件的 `no-drag` 区域覆盖；关闭详情页、打开评论或歌词选择、最大化及全屏时移除。已用商店 Folia 1.2.2 验证，因此恢复拖动不依赖重新安装插件。

## 动态封面范围

设置 → 高级 → 动态背景 → 仅在播放详情页生效。现有开关已覆盖普通页面恢复、详情页启停、切换封面、释放绘图资源和重启后保存。

- `tests/plugin-window-drag.electron.test.cjs`：Windows 原生区域命中、左右按钮可用、移动不改变尺寸、最大化与全屏。
- `tests/folia-lyrics.electron.test.cjs`：13 种样式、时钟、暂停拖动进度、偏移、字体变化及离线重启。
- `tests/kawarp-background.electron.test.cjs`：动态背景范围、资源释放及设置持久化。详情页限定模式下，普通页面本来就没有画布，因此保存测试等待设置提交确认后再读取磁盘。
