| 编号 | 处理结果 |

## 凭据与备份

普通设置保存在 `config_v2.json`，凭据保存在同一用户数据目录的 `credentials.json`。恢复记录本身也加密，避免迁移过程中产生明文临时凭据。系统安全存储不可用、只提供明文后端或无法解密时，显示错误代码和原因，保留原文件，不退回明文保存。

凭据与系统账户绑定；换电脑或导入备份后需重新填写 Cookie 和 WebDAV 登录信息。此变更不会追溯改写已经导出的 `.lxmc`、历史日志或用户另行保存的旧配置副本。

## 开放 API 接入调整

从“设置 → 开放 API”取得端口和令牌。令牌每次启动服务重新生成，本机访问也要携带 `Authorization: Bearer <令牌>`。原有未认证调用及 GET 控制调用需要调整。

```http
GET /status HTTP/1.1
Host: 127.0.0.1:23330
Authorization: Bearer <设置中显示的令牌>
```

```http
POST /volume HTTP/1.1
Host: 127.0.0.1:23330
Authorization: Bearer <设置中显示的令牌>
Content-Type: application/json

{"volume": 50}
```

以上端口仅为示例。读取接口包括 `/status`、`/lyric`、`/lyric-all` 和 `/subscribe-player-status`。播放、暂停、上一首、下一首、收藏、取消收藏、跳转、音量和静音均使用 POST；跳转参数为秒数 `offset`，音量 `volume` 为 0–100，静音参数为布尔值 `mute`。

只有 `/subscribe-player-status` 允许通过 `?token=<令牌>` 供 EventSource 使用，也支持 Bearer 请求头。浏览器跨来源页面不会获得访问权限。订阅返回 429 表示达到连接限制；接收阻塞时服务断开连接，客户端可重新连接获取当前状态。

## 远程扩展接入调整

`window.__lxExtSourcePlugins__.remotes` 不再接受裸 URL 字符串，需要下列声明；摘要占位符须替换为经核对的固定版本文件摘要：

```json
{
  "id": "example-source",
  "version": "1.0.0",
  "url": "https://plugins.example.com/example-source/1.0.0.js",
  "sha256": "<固定文件的64位SHA-256十六进制摘要>",
  "allowedOrigins": ["https://api.example.com"]
}
```

脚本仍导出接收 `env` 的工厂函数。网络通过 `env.httpFetch`，只允许声明的公共 HTTPS 来源和默认端口；拒绝私有网络、IP 地址、重定向及 Cookie 等环境请求头。DNS 检查与实际连接使用同一解析结果。脚本不能读取软件凭据、文件系统或调用软件的其他进程间接口。

限制为最多 4 个远程音源，每个音源 8 个调用、4 个网络请求；初始化最多 10 秒，单次执行最多 20 秒，网络请求最多 15 秒。脚本上限 512 KiB，请求正文上限 512 KiB，响应上限 4 MiB。调用超时会关闭对应沙箱；取消后仍保留执行期限，防止死循环移除超时保护。页面关闭、重新加载或进程异常时释放对应沙箱。

远程接口经异步代理调用；`getMusicUrl`、`getLyric`、`getPic` 保留 `{ promise, cancelHttp }` 形式，其余方法返回 Promise。本地内置工厂、商店插件和用户手动导入的自定义音源属于不同机制；此远程扩展沙箱不代表所有本地插件都已隔离。

## 版本与验证边界

常规版采用 [Electron 43.7.3](https://releases.electronjs.org/release/v43.7.3)。选择 43 是为了在官方支持期内保留 x86；[Electron 44 已停止提供 x86](https://www.electronjs.org/blog/electron-44-0)。Win7 兼容版仍使用 22.3.27，其内核已停止官方支持，无法同时满足 Win7 兼容与新内核支持要求。

依赖扫描中高危和严重问题均为 0，仍有 9 项开发工具链中危提示，涉及开发服务器和构建依赖；没有宣称依赖扫描全部清零。未在真实 Windows 7、Linux 或 macOS 系统上验证，也未生成或发布新安装包。

2026-09-22：92 项基础及兼容性检查、42 项 Electron 检查通过；相关代码 ESLint 和差异格式检查通过；常规版与 Win7 兼容版的主进程、主界面、桌面歌词、预加载脚本均构建通过。构建和临时验证文件位于 Git 忽略目录，未执行整仓所有测试。

基础检查覆盖凭据迁移和失败回滚、备份排除、日志脱敏、IPC、真实 HTTP 认证及订阅限制、更新停滞和摘要缺失。Electron 检查使用独立临时配置和生产构建，覆盖凭据重启恢复、窗口身份、自定义音源、远程沙箱权限和死循环、更新安装、插件生命周期、备份、字体、播放队列和加载错误。其中 7 项安全检查另外在 Electron 22 兼容版生产构建上通过。兼容版也检查 Node 16 图片解析、SQLite、元数据、浏览器登录依赖和插件编译器。
