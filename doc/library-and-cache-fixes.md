## 数据与容量说明

- 历史快照单个歌单保留最近 20 个，全局保留最近 500 个、约 128 MiB；至少保留最新一份。临时播放列表不创建历史快照。
- 听歌记录保留最近 50,000 条。从本次更新后开始记录；老数据没有可靠的添加日期，不冒充“最近添加”。
- 智能歌单来源是所选普通歌单；“已下载完成”依据下载记录，音频被外部删除后可用性仍由播放/文件检查处理。
- 文件夹通知会合并处理，同时每 60 秒补充扫描和检查。关闭监测不删除歌曲或音频；不自动删除失效文件记录。
- 重新关联使用文件名、已知文件大小、时长、歌手、专辑核对。多个候选保留原路径；歌曲 ID 保持稳定。
- 旧本地歌曲缺少年份时，可在“文件管理”中重新读取本地标签；此操作更新曲库信息，不写音频标签。
- “所有数据”备份增加可选择的曲库部分，包含分类、智能规则、监测配置、歌单快照和听歌记录，沿用整体事务回滚。导入后监测暂停，需手动开启。
- 封面内存显示包括仍在使用的图片；清理后这些图片等到界面释放才回收。本地标签内存是估算值，数据库缓存显示逻辑内容大小，不等同于 SQLite 文件的物理占用。
