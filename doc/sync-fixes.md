# 同步问题修复 F01–F12

## 改动

| 编号 | 处理结果 |
| --- | --- |
| F01 | WebDAV 每轮只从数据库读取一次所选内容，用修订号检查同步期间的本地修改。复用本轮哈希和已校验的远端快照，恢复后只返回必要的规范化哈希，不再重新读取整库。 |
| F02 | 有 ETag 时发送 If-None-Match，否则使用 Last-Modified。304 复用正文、解析结果和哈希；首次读取、服务器不支持条件请求或账号改变时正常重新获取。上传继续使用条件写入，拒绝覆盖并发修改。 |
| F03 | 下载恢复的歌单、下载记录、不喜欢列表与设置文件共用 SQLite 事务和文件恢复日志。全部提交后才通知界面；失败时统一回滚，异常退出后的恢复沿用备份恢复日志。恢复前再次检查本地修订号和设置。 |
| F04 | 平台歌单更新使用有上限的并发队列，同平台最多 2 个、总计最多 6 个歌单任务；单个慢歌单不再顺序阻塞全部歌单。同一歌单进行中的更新会合并。 |
| F05 | 各歌单独立记录成功或失败，自动更新等待所有任务各自结束并汇总失败数量。错误显示代码与原因，可从同步状态页重试。 |
| F06 | 设置 → 数据同步 → 同步状态统一展示 WebDAV、平台歌单更新、账号歌单同步、回写及设备连接状态。记录最近成功时间、进度及错误，支持搜索和只看失败；最近 200 个项目的最新状态在重启后保留。连接等待和重连不再算作失败。 |
| F07 | 回写差异、顺序冲突和共有歌曲比较改用 Set/Map，避免每首歌再次遍历完整列表。 |
| F08 | 未变化的回写和平台刷新跳过保存；多个歌单同时修改时合并持久化请求，直接比较快照字段。仍然等待回写意图落盘后才发送平台修改请求。 |
| F09 | 初始化读取失败后清除失败中的初始化任务，下一次初始化、刷新或重试可重新读取；同一时刻仍只执行一次初始化。 |
| F10 | 所有回写接口共用按平台限制的请求队列，同平台最多 2 个、总计最多 6 个请求；真正开始请求前再次检查停用、账号和绑定状态。与歌单任务队列分开，防止嵌套等待。 |
| F11 | WebDAV 冲突和回写冲突显示新增、删除、重命名等差异，回写分别显示本地与平台修改。预览最多展示 100 行并保留总数。账号歌单可全部同步、仅同步所选或忽略所选，支持搜索和批量选择筛选结果。 |
| F12 | 设置 → 数据同步 → WebDAV 音频目录支持根目录、子目录、返回上级、文件名筛选和直接播放。音频进入临时播放队列，支持跳转进度，不会被本地曲库检查误报为文件丢失。 |

## 使用范围

- 平台歌单同步范围用于 Cookie 歌单同步及启动同步。忽略已有歌单不会删除本地数据；单独导入歌单的自动更新开关仍在歌单更新窗口管理。
- WebDAV 音频目录从连接地址对应的根目录开始浏览，与保存同步快照的子目录分开。沿用已保存账号，通过本机临时地址转发音频，歌曲和播放队列中不保存密码。
- 音频转发支持单段 Range、流式背压、正文停滞超时、取消后断开上游、连接数量限制及账号切换检查。目录和音频重定向不向其他来源发送凭据。
- 可浏览 MP3、FLAC、WAV、M4A、OGG、Opus、AAC、WebM；实际解码能力取决于当前 Electron。单个目录最多 5000 项，目录响应最多 2 MiB。音乐文件无需先完整下载到磁盘。
- 本地多类数据恢复具有整体回滚；远端已经接受的上传与本地 SQLite 不是分布式事务。后续本地恢复失败时不推进同步基线，下次同步重新检查双方状态。
- 设备同步服务和连接记录表示服务/连接状态；不会把单个设备连接成功当作所有设备每一次增量修改均已完成。
