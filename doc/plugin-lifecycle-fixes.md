# 插件生命周期修复（G03–G06）

## 使用方式

在「设置 → 插件商店」中，已安装的可选插件增加「停用 / 启用」按钮。停用会移除主窗口和桌面歌词中的插件功能及设置入口，保留安装文件与原配置；重启后仍保持停用，再次启用即可恢复。此开关适用于在线安装和本地导入的插件，内置功能沿用原有控制方式。

插件更新或重新安装成功后删除旧版本，只加载当前新版本。新版本的入口、样式读取或激活失败时，保留新版本并显示错误代码和原因，可在商店重新安装或卸载。按最新需求取消运行时自动回退，并在读取历史登记信息时清理旧回退备份；用户配置及停用状态继续保留。

## 修复明细

| 编号 | 调整 | 关键保护 |
| --- | --- | --- |
| G03（按最新需求调整） | 不保留旧版本，不再自动回退；主窗口和桌面歌词只加载新安装版本。 | 安装包校验、文件落盘及登记成功后删除旧目录；安装提交失败时原安装不受影响；加载失败显示代码及原因；忽略旧任务迟到报告，主窗口加载成功不会清除桌面歌词的失败记录。 |
| G04 | 卸载、停用和整体退出时隔离每个插件的清理错误，等待异步清理完成。 | 插件退出回调失败后仍清理宿主作用域、样式及模块缓存，继续同步和清理其他插件，并显示清理异常提示。 |
| G05 | 清理安装目录内的入口及所有依赖模块缓存，包括延迟加载和加载失败时留下的依赖。 | 同时移除父模块对子模块的引用；不清除安装目录外的宿主或共享模块。 |
| G06 | 统一提供保留配置的停用与启用能力，并保存状态。 | 两个窗口同步状态；停用后不会执行插件入口；更新、导入和重启不会自行重新启用。 |

## 验证

最新验证及统一错误提示的说明见 [加载错误提示](loading-error-fixes.md)。构建输出保留在忽略目录中。

- 管理器与运行时测试覆盖：新安装删除旧版本、两处界面加载失败仍保留新版本、历史回退记录及目录清理、登记写入失败、迟到报告、连续更新、异步退出异常、完整依赖清理及停用状态持久化。
- Electron 测试使用生产构建及独立临时用户目录，实际安装插件、制造主窗口和桌面歌词加载失败、停用、重启、启用和卸载；验证另一插件正常工作且配置保留。
- 兼容性检查覆盖现有插件商店、动态插件发现、设置面板、源码 ZIP 与 LXPlugin 的导入导出、离线启动及插件开发工具。

安装完成后只有新版本目录属于该插件的当前安装。保留用户偏好文件不代表保留旧版插件程序。
